# URL 用途合同

统一由 `input_safety.parse_public_url` 验证结构、协议、主机、端口、长度及百分号转义。错误返回结构化代码和安全摘要；未知字符集的合法字节不是畸形 URL。

主机身份统一使用发布依赖 `idna` 的 IDNA 2008／非过渡式 UTS #46（`transitional=False`），不在转换前做 Unicode casefold。Unicode 与对应 Punycode 收敛为同一 ASCII 身份，但协议上不同的兼容字符主机不折叠为同站。严格传输、页面去重、域名、平台、工具绑定和来源统计复用同一主机转换；路径、查询、未知百分号字节与隐私规则不改变。缺少依赖时明确安装依赖，不静默回退旧转换。既有旧身份或定位不能手改哈希延用，应重新采集或使用已有维护重建入口后重新准入；维护重建仅接受其支持的原始事实，不把不支持的证明类型伪装为签章。

| 用途 | 接口与原始字段 | 允许变换 |
| --- | --- | --- |
| 原始事实 | 请求 `url/request_url`、宿主 `final_url`、签章 `redirect_chain` | 不以展示或脱敏副本覆盖 |
| 签章绑定 | `source_identity.strict_url_identity` | 主机与协议大小写、匹配协议默认端口、空路径；不发送的片段不参与请求身份 |
| 跳转节点 | `source_identity.redirect_node_identity` | 与严格传输同一规则；每条实际链独立 visited 集合 |
| 页面去重 | `source_identity.page_url_identity`；兼容名称 `canonical_url` | 仅发布版明确等价规则；采用经验证的最终响应 URL |
| 隐私展示 | `input_safety.privacy_url_component`、`redact_text`、`assert_public_text` | 仅显示副本可解码或遮蔽；不得反馈至签章、URL 哈希、页面去重 |

严格身份保留请求目标的尾斜杠、默认首页、分号参数、空分隔符、跟踪键、参数顺序、重复键、空值、加号及百分号字节拼写。循环判断不得调用页面去重接口；正常清理跳转不等于循环。当前收据不含请求方法变更合同，不自行推断方法；不扩展新的网络请求功能。重试属于不同观察，不共享 visited。

页面查询按原始有序片段处理，只解码识别参数名所需的信息；明确跟踪键可删除，其余业务值不经有损文本解码。保留空组件、是否有等号及相对顺序；百分号大小写统一，可还原非保留 ASCII 字符；编码的保留字符不变成结构分隔符。加号不自动视为空格，不猜字符集、不二次解码。含签名或鉴权参数的目标保守保留，不删除看似跟踪的参数；正式来源仍须通过既有敏感参数门禁。

页面路径保留默认首页名称、尾斜杠、重复斜杠、点段、路径大小写及编码点/斜杠，不用文件系统路径规则或网站惯例推断服务器路由。默认首页与根路径、带尾斜杠与不带尾斜杠的路径，不因字符串形式自动等价；编码点或斜杠只统一十六进制大小写，不转成结构。没有实际最终响应等价依据时，潜在不同资源保持不同 URL 身份；经现有来源链验证的同一最终 URL 仍可去重，正常首页或尾斜杠跳转仍可使用。相同正文的碰撞规则不变，不同正文不能只因路径折叠合并。旧身份、页面计数和审计随规则哈希变化失效，不修改旧记录后强行沿用。

`legacy_sorted_normalized_url_sha256` 仅用于识别可严格解码的旧排序表示，未知字节返回不可识别。它不能授予正式身份兼容；正式哈希只接受当前规则。实际打开数量按严格请求身份检查下界，页面门槛按最终页面实体检查，两者不互相代替。

隐私副本只解码一次。内容编号豁免仅适用于有明确内容上下文的纯数字且只命中手机号形态的值，不豁免邮箱、明确联系方式、账号或个人主页。编码邮箱同样受保护；公开叙述中的此类 URL 整段等长遮蔽，原始收据与私有响应不变。公开来源 URL 若含确认的个人标识则拒绝准入，不得修改 URL 来伪装通过。

## 身份规则变更与历史事实

运行中的发布版和已冻结真值只读；不能把旧状态指向新代码，也不能同时接受冲突的新旧哈希。旧任务可继续使用原完整发布快照。修改身份、提取或隐私规则后，旧采集衍生字段和依赖审计失效；旧分数、平台统计、维度结果与成果封印不得沿用。

发布维护阶段可显式执行以下只读原件、独立目录重建：

```text
python scripts/source_capture.py rebuild-identity --manifest "<原采集清单>" --expected-manifest-sha256 "<已核验原件哈希>" --output-dir "<独立重建目录>"
```

该入口验证原件哈希、事件链、当前受信签章、原始请求和最终响应的逐字对应、标题与原始正文哈希，保留旧清单及原收据，重新生成当前 URL、隐私、区块和平台身份。不得执行旧代码、猜测替换字符、补写原始 URL 或重新签章。正文缺失、原始 URL 无法与签章对应、标题已不可逆丢失等情况返回身份不确定/原始事实缺失错误，并保持不准入。

输出为 `rebuilt_not_admitted` 的维护候选包，不是正式台账，不注册正式写入，也不承诺新研究可复用旧研究事实。重建包原子提交；相同输入重复调用须复核现存工件且不追加，冲突拒绝，失败仅清理本次拥有的暂存目录。发布迁移必须重新核对同一任务的原查询/执行事实，并通过受保护的采集及准入流程重建全部下游；未完成这些步骤的包始终不可审计评分。新地点研究仍须重新取得本次事实。
