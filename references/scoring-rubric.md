# “7+1”编码与跨平台评分规则

## 1. 编码单位与评分前提

先严格区分三种机器可读数量：

- `retrieved_evidence_units`（检索有效证据）：进入证据台账、有效、直接、具有唯一主维度并在该主维度内去重的广义研究证据；
- `eligible_evidence_units`（评分候选证据）：逐条通过正式评分准入规则并在主维度内去重的记录；
- `scored_evidence_units`（实际计分证据）：候选记录所在“平台×维度”达到发布协议最低样本量后，真正进入平台维度倾向值计算的记录。

三者不得共用一个模糊的“主要证据数”。页面数、检索证据数和候选证据数都不能代替实际计分数。

一个经去重、可读取、与地点直接相关且非推广的用户帖子、评论、回复或游记只是原始候选材料。单条正式评分资格由发布协议和 `scripts/formal_scoring.py` 唯一判定；至少同时要求 `used_for_scoring=true`、`is_valid=true`、`is_direct_place_evidence=true`、`score_scope=direct`、允许的证据类型、唯一有效 `primary_dimension`、同维去重、合格评分值、可靠性和置信度达标、语义量化已确认且原文摘要完整。任何脚本不得自行维护较宽或较窄的另一套准入条件。

同一原始文本包含不同方面或相反观点时，先拆分为可独立判断的语义单元并分别编码。每个正式评分单元必须具有独立 `evidence_id`、独立 `semantic_unit_text`、唯一 `primary_dimension`、独立情感与评分字段；正式维度归属只读取 `primary_dimension`。`dimension_tags` 和次维度只用于主题覆盖、检索缺口与定性说明，绝不用于满足 25、40、60 条门槛或把同一评分单元计入多个维度。真正拆分后的独立单元可以来自同一原始页面，但同一 `dedup_group` 在同一主维度内只能计一次；转载、镜像和重复采集不能借拆分增加样本。

正式证据目标按所选逐维置信等级派生：默认中高为每维 40 个，在一条证据只对应一个主维度时七维理论最低 280 个；历史兼容值 100 只作早期警戒和旧状态兼容，不是默认完整评价的正常终止规模。任一维未达目标时自动开展缺口导向迭代；受控预算、轮次或合法公开路径终止后仍不足，使用实际最大样本形成受限交付并披露缺口。任何任务级总量都不能替代逐维证据门槛。

以下情况填写 `null` 或“数据不足”，不得机械赋 0 倾向或 50 转换分：

- 只有官方事实、宣传、媒体报道或专业判断；
- 只能看到综合星级、评论总量、搜索摘要或互动量；
- 没有直接涉及本维度的公众感知；
- 无法确认与研究对象直接相关；
- 证据全为推广、转载、镜像或重复内容；
- 语义候选尚未通过自动门槛或人工复核。

缺少原生数值的文字须按 `semantic-quantification-methods.md` 核对发布锁定的评价协议与代码簿 SHA-256，再完成语义单位切分、七维归属、方面级极性、强度、上下文修正、置信度和复核。单次任务不得在线更新或改写评分规则。原生星级或量表值写入 `native_rating_*`，研究者语义推断写入 `semantic_*`，两者不得混作同一测量来源。

## 2. 七个维度与初始研究权重

维度名称、定义和边界以 `seven-plus-one-framework.md` 和 `scripts/dimension_framework.py` 为唯一规范：

1. 历史文化感知；
2. 在地文化特征；
3. 生活文化延续；
4. 文化实践体验；
5. 场所氛围体验；
6. 保护活化感知；
7. 承载治理体验。

七维基础聚合使用下列“初始研究权重”。该组权重用于本 Skill 的默认标准化比较，不表示底线问题可以互相补偿：

| 维度 | 权重 | 设定依据 |
|---|---:|---|
| 历史文化感知 | 15% | 反映对历史价值、文化底蕴与地方记忆的识别、理解和情感反应 |
| 在地文化特征 | 15% | 直接检验地方文化辨识度、文化真实性与同质化风险 |
| 生活文化延续 | 20% | 以真实主体、日常使用、传统业态和社区记忆的持续存在为活态传承核心 |
| 文化实践体验 | 15% | 检验技艺、民俗、节庆、教育与活动是否真实发生并形成公众参与 |
| 场所氛围体验 | 10% | 反映历史环境、社会活动与文化内容共同形成的场所感受，但同时受多类因素影响 |
| 保护活化感知 | 15% | 检验保护、修缮、适应性利用及传统与现代关系的公众评价 |
| 承载治理体验 | 10% | 反映使用压力、秩序、安全、客流、环境与利益协调，是活态传承的支撑条件 |

记 `H`、`L`、`C`、`P`、`A`、`R`、`G` 依次为上述七维转换分，则：

`S = 0.15H + 0.15L + 0.20C + 0.15P + 0.10A + 0.15R + 0.10G`

该组权重固定称为“初始研究权重”。后续如采用专家赋权、层次分析、德尔菲法或实证模型形成替代权重，必须保留初始权重结果作基线，在方法、全部替代值、总和、来源与影响中正式披露；不得静默覆盖。“历史文化活态传承感知评价”是七维共同形成的结果层，不另设并列权重，也不得作为第八项再次参加聚合。

主体、时间和情感只作横向标签：

- 主体：本地居民、商户、游客、传承人或文化实践者、管理者、专业人士、其他公众；
- 时间：当前状态、历史回忆、改造前后比较、长期变化、工作日、周末、节假日、节庆活动期间、白天、夜间；
- 情感：正向、负向、中性、混合。

## 3. 提及率等级

仅在能够确认该平台与该维度的有效分母时计算：

| 等级 | 比例 |
|---|---:|
| A | `>=50%` |
| B | `>=30% 且 <50%` |
| C | `>=15% 且 <30%` |
| D | `>=5% 且 <15%` |
| E | `<5%` |
| U | 无法判断 |

分母是该平台可用于本层分析的去重有效用户样本，不是查询数、网页数、平台显示的评论总量、搜索排名、点赞量或播放量。同一去重样本对同一主题最多计一次。分母不可核实时使用 U，不得给出虚假精确比例。

## 4. 倾向分与转换分

| 倾向分 | 含义 | 转换分 |
|---:|---|---:|
| +5 | 几乎全部为强烈正面 | 100 |
| +4 | 正面明显占主导 | 90 |
| +3 | 正面较多，少量负面 | 80 |
| +2 | 正面略多于负面 | 70 |
| +1 | 正面稍多 | 60 |
| 0 | 足够证据显示正负基本均衡 | 50 |
| -1 | 负面稍多 | 40 |
| -2 | 负面略占优势 | 30 |
| -3 | 负面较多 | 20 |
| -4 | 负面明显占主导 | 10 |
| -5 | 几乎全部为强烈负面 | 0 |

转换公式为 `(倾向分 + 5) × 10`。0 只表示有足够证据支持均衡判断，不能表示数据不足。

语义连续分先由代码簿线索贡献和上下文修正计算，再映射到 `[-5,+5]`。只有 `semantic_review_status=auto_eligible` 或 `human_confirmed`，且语义置信度、维度置信度和证据可靠性均达到本次代码簿阈值的记录才可计分。`review_required`、反讽风险、维度冲突、无方向线索或无法定位原文的记录保留在台账但不计分。

平台内部的文字权重为 `semantic_confidence × evidence_reliability`，只处理编码不确定性；不得用点赞、播放、回复、排名或作者知名度加权。

## 5. 逐维证据置信度与终止规则

每维从 `scored_evidence_units` 及同一实际计分集合对应的独立来源页面和实际来源类型独立复算正式评分置信度：

- `高`：至少 60 个证据单元、30 个独立来源页面、5 类实际来源；
- `中高`：至少 40 个证据单元、20 个独立来源页面、4 类实际来源；
- `中`：至少 25 个证据单元、12 个独立来源页面、3 类实际来源；
- `待深检`：低于中且未通过严格独立穷尽审计；
- `低` 或 `数据不足`：低于中，但严格穷尽审计已经通过。

“中”是正式评价最低要求，不是正常停止条件。正常终止目标为中高或高，状态写 `sufficient`。仅达到中时仍写 `needs_iteration` 并进入本维增强检索，除非通过以下更强的中置信度终止审计：

1. 同维累计至少五轮定向检索；
2. 至少三轮明确标记为 `medium_enhancement`，每轮至少十条实际执行查询；
3. 增强检索覆盖至少六类目标来源、正负两条检索路径、至少三类主体和三类时间情境；
4. 最终增强轮记录 `exhausted`；
5. 最近三轮每轮新增本维证据均少于 2 个，且增强查询跨台账关联至少 20 个相关页面、5 个域名、4 类实际来源；或者最终增强轮全部为 `blocked`/`no_results`，且关联至少 10 个相关页面、4 个域名。

强审计通过后状态为 `sufficient_at_medium_after_audit`。报告必须显示增强轮次和审计依据；仅写“已穷尽”、手填布尔值或模型自由判断不具有放行效力。

低于中置信度的例外至少要求：四轮同维定向检索、每轮八条实际查询、五类目标来源、最终轮 `exhausted`，并通过查询—页面—证据跨台账低增益或阻断路径审计。未通过时维持 `needs_iteration`，不得评分定稿。

## 6. 平台内部评分

先按统一单条资格规则形成 `eligible_evidence_units`，再按发布协议对每个“平台×维度”执行最低样本门禁。当前协议门槛从 `evaluation-protocol.json` 读取，不得由脚本另写常量或按任务降低。候选数未达门槛时，该组合必须写：`scored_evidence_units=0`、正中负计分数均为 0、`minimum_sample_met=false`、`platform_sample_status=insufficient_platform_samples`、`tendency=null`。达到门槛时，全部合格候选才形成该组合的实际计分集合，并用同一集合计算正中负数量、加权倾向值和转换分。

每个平台维度对象至少记录候选证据数、实际计分证据数、计分正中负数量、最低样本门槛、门槛状态、倾向值和转换分。可以另报宽口径语义正中负统计，但必须明确标为非计分统计，不能与正式计分构成混用。

先分别形成每个平台的七维结果，记录实际计分直接用户样本、各维倾向分或 `null`、转换分、提及率等级、证据充分度、平台七维基础分及覆盖权重。

七维均有可用分数时：

`平台七维基础分 = Σ(七维转换分 × 该维初始研究权重)`

即 `S = 0.15H + 0.15L + 0.20C + 0.15P + 0.10A + 0.15R + 0.10G`。

存在缺失维度时，只可另算并标明 `partial_platform_score` 作为诊断值，同时报告 `coverage_weight`；正式 `platform_score` 留空。不得将缺失权重重新分配给其他维度。

平台有效用户样本少于 5 个时仅作补充，不纳入正常跨平台综合。只有所有平台均少于 5 个时才可启动 `all_small_exception` 展示探索性结果，并标低可信度。

## 7. 跨平台综合

不得把所有平台样本直接混合评分。先形成平台结果，再分别计算：

- 平台等权综合分：对符合纳入规则的平台分作算术平均，作为默认主结果；
- 样本加权综合分：按可核实的实际有效样本数加权，任一平台权重原则上不超过 50%，并输出实际权重。

样本计数不可比、只是平台总量、单元定义不同、只有一个平台或平台间维度覆盖差异过大时，样本加权分只能作敏感性参照或写“数据不足”。

跨平台每维只使用该维有分数的平台，并报告可用平台数。七个跨平台维度均有结果时，七维基础综合分按初始研究权重聚合；任一维缺失时，平台等权综合、样本加权综合与建议最终分均留空，不得重分配缺失维度的权重。这里的“平台等权”只描述不同平台之间的合并方式，不表示七个分析维度等权。

`scored_evidence_units` 必须能逐条追溯到形成平台倾向值的记录；跨平台结果同时记录有效计分平台数和实际计分证据数。若候选证据很多但分散到多个未达最低样本量的平台，可以表现为高候选数、0 实际计分数和数据不足，不能以候选数量给出中高置信度或正式分数。

## 8. 总体情感结构

正式评分的正向、中性、负向数量只从 `scored_evidence_units` 计算，且三者之和必须严格等于实际计分证据数。定性研究可另报检索证据或候选证据的宽口径情感结构，但必须与计分统计分栏。混合文本按发布协议归入确定方向或保留为非计分混合记录，不得同时计入正面和负面以凑比例。

输出正面、中性、负面三个 10 个百分点区间。区间应共同覆盖 100% 的可能结构，并说明是基于可识别用户样本统计还是当前检索估计。

## 9. “+1”结果层与不可补偿性

结果层固定为“历史文化活态传承感知评价”，必须同时输出：综合分、核心优势、核心风险、底线性问题、证据充分度和评价置信度。

综合分以七维初始研究权重聚合分作为参考，但在解释之前必须检查：

- 在地文化真实性是否明显受损；
- 居民、商户、传承人等真实主体是否退出；
- 日常生活或文化实践是否消失、表演化或空心化；
- 保护真实性、完整性或安全底线是否受损。

任一底线性问题成立时，其他维度高分不能将其抵消。结果层必须显著说明风险和影响，不得仅凭综合分给出“良好”结论。`bottom_line_override_checked` 必须为真，且其依据可追溯到本次证据。

## 10. 建议最终分与可信度

同时列出平台等权分和样本加权分。样本不可比时优先平台等权；计数准确且覆盖结构相近时可采用样本加权。两者差异明显时分析原因，不得随意取平均。任何人工调整必须保留调整前值、理由和方向。建议分保留一位小数，倾向分保持整数。

总体可信度综合考虑来源结构、可读性、独立性、时间覆盖、主体覆盖、跨平台一致性和逐维证据状态。语义置信度、证据可靠性、维度证据充分度和总体评价置信度必须分栏，不得合并成不透明单值。

## 11. 禁止做法

- 用官方价值、资源名录或宣传提高公众感知分；
- 用网页数量、搜索排名或互动量代替提及率；
- 用平台总评分推断七维倾向；
- 把人多、商业旺或网络热度高等同于活态传承；
- 把数据不足维度填为 0 倾向或 50 分；
- 用其他维度补偿、删除缺维或重新分配权重；
- 用模型文字或单个 `exhausted` 字段证明检索穷尽；
- 把 `area_aggregate` 周边结果当作地点直接分；
- 重复计算转载、镜像、同文案或同一证据组；
- 把未复核的语义候选写入正式分数；
- 用 `dimension_tags` 把同一证据 ID 重复计入多个正式评分维度；
- 用检索证据或候选证据的正中负构成解释由另一小组实际计分样本产生的分数；
- 为避免 20 分或 100 分而人为截断分数区间；
- 用高综合分掩盖真实性、主体连续或文化实践等底线损失。
