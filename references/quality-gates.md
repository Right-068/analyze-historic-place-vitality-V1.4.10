# 交付前质量门禁

执行来源前置门禁统一使用 `execution_facts.py`、`execution_semantics.py` 与 `execution-facts.md`：状态锚点及显式上下文、真实已提交计划、唯一查询定义、连续首试/重试链、唯一执行身份、真实时间与因果一致、来源实际执行绑定和状态数量矩阵均须成立。接收顺序不代表事件顺序；迟到独立事件合法时保留真实时间，查询事实哈希排除接收序号。未知计划、冲突查询、重复执行、异常因果时间、损坏登记或缺上下文为硬失败。失败尝试计资源但不计有效覆盖；零打开、无结果或失败执行不得支撑正式来源，相关来源页数不能超过实际相关页数。非法来源和证据逐层排除并重算，目标达成文本不能覆盖错误。独立意图和实际尝试分别核算，合法重试不增加覆盖。事务恢复固定实际引用的不可变计划、查询与安全前缀，不依赖无关新计划导致的登记表整体哈希变化。逻辑集合哈希与原始字节哈希各司其职。

逐项检查。任何“失败条件”存在时，不得宣称正式报告已经完成。

## 1. 输入与范围

- [ ] 已遵守总原则：研究规则、审计规则和发布版代码高于执行 Agent 的自主判断；只能补充数据，不能补充资格；只能修复格式，不能修复结论；不得通过修改状态、脚本、评分或审计结果提前完成任务。
- [ ] 初始化时已生成正式 Skill 的发布版完整性清单，运行期间受保护文件保持只读，当前哈希与初始化值完全一致。
- [ ] 唯一正式阶段顺序为 `INITIALIZE → SEARCH → EVIDENCE_BUILD → SEMANTIC_QUANTIFICATION → EVIDENCE_AUDIT → SCORE → REPORT_BUILD → VALIDATE → DELIVER`；不存在越级、倒序或旁路调用。
- [ ] 地点、城市或行政区、对象类型、空间范围和检索截止日明确。
- [ ] 收到可识别地点后已经直接开始执行；可由官方资料自行消歧或采用默认时间范围、输出目录时，没有把常规确认作为启动条件。
- [ ] 同名地点已经消歧。
- [ ] `poi`、`area_direct` 和 `area_aggregate` 已区分。
- [ ] 区内 POI 聚合未冒充街区直接评价。
- [ ] 时间范围、旧称、别称和代表节点已记录。
- [ ] 用户指定的唯一输出目录已采用；未指定时使用并记录当前平台允许的任务或下载目录，无需为此暂停确认。
- [ ] 最终文件名采用地点和日期，未写入平台临时路径。

失败条件：运行期修改正式 Skill 或受保护规则；状态机越级；研究地点仍有歧义；边界不明却给出精确评分；把商户评价直接上推为街区整体体验。

## 3. 页面门槛和来源多样性

- [ ] 来源台账包含不少于 150 个去重后的相关页面实体。
- [ ] 150 指由规范 URL、最终跳转、内容指纹、碰撞状态和可信独立出现复核形成的页面实体，不是 `source_id` 数量、查询次数、搜索结果显示量或评论条数。
- [ ] 每个页面都有真实 URL、标题、平台、域名、来源类型、检索编号、实际检索词、检索日期和读取状态。
- [ ] 页面数、可读页面数、受限页面数、用户来源页数、检索有效证据数、评分候选证据数和实际计分证据数分别统计。
- [ ] 实际计分证据目标从锁定协议的所选逐维置信等级派生；默认中高为每维 40、七维理论最低 280。历史兼容值 100 只作早期警戒和旧状态兼容，不是默认完整评价的正常终止规模。
- [ ] 七维共同达到中、中高、高的理论最低实际计分总量分别为 175、280、420；总量只作资源提示，任一维未达到本次目标时均不得写 `target_met`。
- [ ] 任一维未达到所选目标时已自动启动缺口导向深度检索，不等待用户确认；计划记录与执行记录分别统计，只有具有执行凭据的真实尝试计入轮次、预算、覆盖、低增益和穷尽。
- [ ] 基础检索只使用第 0 轮，深检轮次只允许第 1 至第 5 轮并连续形成；任何越界执行记录均从所有统计排除并阻断终态。普通轮每个适用维度分别至少 8 条独立查询，增强轮每个适用维度分别至少 10 条；全局总量、其他维度超额或重复意图不能补偿。检索控制、状态恢复、正式审计和最终验收调用同一共享验证器，没有用最大轮次编号替代完整轮次证明。
- [ ] 同一路线只采用最新有效状态；任何继续、重试、等待、运行或新增证据状态均阻止维度终止。维度终止时终止路线数严格等于尝试路线数，`source_blocked` 仅用于全部路线确实阻断、失败或耗尽。
- [ ] 持续不足时已核查所有适用来源族和查询族；仅按发布配置的逐维轮次、查询覆盖、低增益或阻断追踪及机器绑定独立穷尽审计判定终态。三轮、少量增益或路径受限本身不授权穷尽与交付。
- [ ] 已尽可能覆盖官方、开放数据、名录、场馆、新闻、专业、学术、百科、其他评价、地图、旅游 UGC、其他社交、博客、论坛、社区和目录来源。
- [ ] 至少尝试十类适用来源；能够获得时，建议实际覆盖不少于八类。
- [ ] 未覆盖类型记录了无结果、访问限制或不适用原因。
- [ ] 正面和负面查询均执行，或已说明无法执行。
- [ ] 大众点评和小红书未被当作必需来源；默认剔除的说明同时包含未登录访问限制、另有独立获取路径、后续综合分析用途以及避免重复样本/重复计数/证据层混淆。
- [ ] 默认剔除这两个平台时，没有把其缺失误写为研究失败，也没有与另行获取的数据重复计数。

失败条件：去重相关页面实体少于 150；任一维未达到所选逐维目标却未自动深检或无受控终止依据；把历史兼容值 100 当作默认完成门槛；用检索证据或候选证据替代实际计分数；总量达标但任一维缺口仍宣称目标达成；用同页不同参数、转载、镜像、分页、不同来源编号、同内容不同 URL 或无关同名页面凑数；虚构 URL；来源高度单一且未扩展或解释。

## 4. 采集、准入、三类台账与去重

- [ ] 每次页面读取均先形成追加式采集事件和内容寻址快照；再次访问同一 URL 产生新版本，没有覆盖旧快照或旧采集事件。
- [ ] 原始响应先写入同目录事务专有临时文件，经刷新、`fsync`、大小和 SHA-256 复验后原子改名；事务日志固定目标、临时文件、阶段与所有权。中断恢复只清理所属临时文件，保留哈希一致的共享成品，未知冲突失败封闭，重复恢复与重试不产生半写成品或重复事件。
- [ ] 并发采集和受保护写入把事件编号、采集追加、提交后清单哈希、写入台账登记、刷新和提交标记置于同一跨进程事务；每笔提交有唯一 `transaction_id` 和 `capture_event_id`，写入台账引用具体事件。24 个并发进程连续五轮不会生成重复编号、断链、过期哈希或丢行。
- [ ] 截断尾行、进程中断和 `WAIT_ABANDONED` 通过写前日志与显式恢复检测处理；没有用随机等待、静默截断完整历史或重写清单掩盖竞争，命令只在两个正式工件均提交后返回成功。
- [ ] 候选来源与候选证据位于暂存层，可编辑但未计入 150 页、历史兼容警戒值或逐维 25/40/60 门槛。
- [ ] URL 规范化保留 `from`、`source`、`ref` 与未知业务参数，并保留查询参数及重复同名参数的原始相对顺序；区分 `%2F` 和 `/`，只删除协议匹配的默认端口，不无依据合并 HTTP/HTTPS。旧排序参数哈希只作兼容读取，页面归并或不归并依据可审计且所有统计调用同一实现。
- [ ] 宿主收据使用独立的严格传输身份逐跳绑定请求与最终 URL，路径参数、查询顺序、重复键和编码差异均不可由页面去重规范化消除；严格身份与页面实体身份没有互相替代。
- [ ] 平台身份由集中别名配置派生，原始主机、规范主机、`platform_id`、规则及来源可追溯；未知平台保守独立，评分、门槛和报告使用同一 `platform_id`。
- [ ] 新增正式来源与正式原始证据只通过 `pre_admission_audit.py` 整批原子提升；任一记录失败时该批没有留下部分正式提交。
- [ ] 每个文本证据具有可复验的采集编号、快照哈希、正文块、字符范围和定位哈希；候选原文逐字存在于不可变快照。
- [ ] 无正文原生数值记录回连采集事件中的原始数值、量表上下界、评价对象、平台、页面实体、采集时间、来源和快照；未伪造文本定位或摘要原文，也未由候选层改写数值。
- [ ] 采集层 `source_type` 是来源类型真值；候选 `source_category` 冲突时已恢复采集值并登记审计，非法值被拒绝，来源统计未被候选声明改变。
- [ ] canonical 来源和证据为追加式不可变记录；纠错仅通过哈希链中的 `retract` 或 `supersede` 事件完成，当前有效视图可由 canonical、纠错与碰撞状态确定性重建。
- [ ] 来源平台由 URL 和正式来源记录派生；候选平台、域名或来源类型冲突导致批次拒绝，没有静默覆盖。
- [ ] 完全重复、高相似、转载、镜像、重复提取、模板尾句与跨批碰撞均进入统一碰撞审计；完全一致未同时重复记为高相似，短长文本规则一致，`unresolved_collision` 未进入评分。
- [ ] 候选自报独立出现未被采信；只有不同页面实体且通过受信任签章复核的 `verified_independent_occurrence` 才能分别计数。
- [ ] 页面实体审计列出每个实体的成员来源与合并理由；统一 URL/平台身份处理默认端口、片段、跟踪参数、参数原始顺序、尾斜杠、`www`、移动/桌面呈现、默认首页与最终跳转，同时保留业务参数且不把未知服务子域过度合并。
- [ ] 提升批次保存候选输入内容寻址归档、前后记录摘要、输出哈希与提交哈希链；归档或任一正式输出被修改时提交复验失败。

- [ ] 检索日志一行一次实际查询，包括无结果和受限查询。
- [ ] 来源台账一行一个页面。
- [ ] 证据台账一行一个可独立编码单元。
- [ ] 每条证据具有“摘要原文”，内容来自本次可见页面且与“必要摘录/匿名化摘要”明确区分；摘要原文不可由模型补写。
- [ ] 三类台账中的非空记录具有相同的 `task_run_id`。
- [ ] 来源通过 `query_id` 关联检索日志。
- [ ] 证据通过 `source_id` 关联来源页面。
- [ ] 页面层和证据层使用独立去重组。
- [ ] 正式评分只按唯一 `primary_dimension` 归属；`dimension_tags` 只用于主题覆盖、检索缺口和定性说明，未增加任何维度的候选数、实际计分数或置信度。
- [ ] 同一原始文本中的多个可独立评价方面已经切分为不同 `evidence_id` 和独立语义文本，每个单元只有一个主维度；同一证据 ID 未在多个正式维度重复计分。
- [ ] 同一机器正式去重键只形成一份候选证据；可编辑 `dedup_group`、证据编号或来源编号不能制造新样本，真正独立的跨维语义单元与转载、镜像、重复采集可以区分。
- [ ] URL 已去除跟踪参数和片段。
- [ ] 转载、镜像、跨平台搬运和聚合转载已关联原始来源。
- [ ] 搜索摘要、仅评分、仅元数据和不可访问页面未计入完整用户样本。
- [ ] 平台 AI 摘要未拆成多个虚构用户单元。
- [ ] 宣传和疑似付费推广未纳入普通用户评分。
- [ ] 高互动内容未按点赞或播放量加权。

失败条件：采集快照、定位或准入提交不可复验；候选数据直接进入正式统计；未授权脚本新增或覆盖 canonical；部分批次被接受；来源和证据无法关联；并发写入产生重复编号、断链或丢行；候选来源类型覆盖采集真值；候选碰撞自证被采信；重复页面实体或重复评论多次评分；把平台显示评论总数称为实际读取数；用 AI 汇总生成虚假样本。

## 5. 编码和评分

- [ ] 采集和来源保存一致的正文格式、正文依据和可见性等级；静态 HTML 没有冒充工具渲染正文。未确认静态内容仅保留候选/非用户背景，用户叶块准入、来源资格和正式计分均拒绝；最终从原始响应重提取并复验块、定位和缓存绑定。
- [ ] 人工决定及独立出现复核均通过发布前审核人身份、权限和密钥绑定；最终消费者使用同一公开验证证明，不把任意本地 HMAC 密钥、来源字符串或缓存标记当作授权。空人工信任配置不全局阻止普通工具和自动合格证据。

- [ ] 工具可追溯来源具有本次实际页面读取引用及原始结果，绑定任务、计划、执行和采集；可选宿主签章存在时还需验签，失败不能降级。缺少签章/IP 不否决完整工具溯源；搜索卡片、无读取依据的自报或伪造调用不能冒充正文来源。
- [ ] 请求/发现入口和最终内容身份分开；页面哈希、内容域名、平台及穷尽依据从同一最终身份重新派生。
- [ ] 正文块布尔值与偏移严格类型检查、叶子块不重叠、文本与块/正文/规则哈希独立复验；重排不改变结论。
- [ ] 正文块类型与用户属性使用同一发布矩阵：官方事实、新闻、学术和元数据块为非用户内容，帖子、评价、评论和回复块为用户内容，`page_body` 仅作上下文；冲突在采集、准入、核心审计、正式资格和最终验收均硬失败。机构页面中的真实用户内容只有独立定位为用户叶块时才可进入评分，背景事实仍排除。
- [ ] 原生数值全链有限，JSON 拒绝非有限常量和重复键，错误 URL 返回结构化安全摘要而不使全量审计崩溃。
- [ ] 标题、摘要、正文、日志与实际重开的 DOCX/XLSX 不含无关联系方式；URL 数字按参数名和路径语境区分内容编号、明确联系方式与歧义项，明确联系方式硬失败，歧义不被误报为确认泄露且签名 URL 未改写；原始响应隔离限权，网页指令从未成为控制参数。

- [ ] 正式 Evidence Audit 只在语义量化、必要人工复核、发布版派生字段完成并刷新检索日志计分数量后运行；未处理候选证据没有提前产生七维缺口。
- [ ] 人工复核只通过固定决定合同和追加式变更台账写入；人工文件未填写或修改正式资格、平台计分标记、倾向值、转换分、加权分或综合分，复核后已重新运行发布版确定性派生。
- [ ] 机器维度审计绑定同一 `task_run_id` 及来源、检索、正式证据精确摘要；评分底层入口重新验证审计、协议版本和正式评分输入封印，没有手动调用旁路。

## 6. 解释与论证

- [ ] 时间变化有前后时段实质证据，不只依据发布日期。
