# 历史文化街区活态传承网络定性分析“7+1”框架

## 1. 框架定位

本框架用于通过本次公开网络证据，识别空间数据、POI 数据、建筑数据和交通网络难以直接量化的公众感知。它与客观空间形态、功能配置和交通条件分析互补，不重复评价路网、建筑密度、功能混合、设施供给或交通中心性本身；只有当这些客观条件进一步形成公众可感知的历史意义、地方特色、真实生活、文化参与、场所氛围、保护活化或承载治理体验时，才进入本框架。

“活态传承”不是与其他项目并列的第八个分析维度。七个分析维度用于观察传承主体、传承空间、传承活动或业态如何持续存在和被公众感知；最终共同形成结果层“历史文化活态传承感知评价”。网络热度、人流或商业繁荣只说明空间活跃，不能替代居民连续、真实使用、文化实践和文化再生产的证据。

七个维度的名称、顺序和边界固定如下，不得改名、增删、合并、拆分或用旧框架名称替代：

1. 历史文化感知
2. 在地文化特征
3. 生活文化延续
4. 文化实践体验
5. 场所氛围体验
6. 保护活化感知
7. 承载治理体验

结果层名称固定为：历史文化活态传承感知评价。

七维初始研究权重固定为：历史文化感知 15%、在地文化特征 15%、生活文化延续 20%、文化实践体验 15%、场所氛围体验 10%、保护活化感知 15%、承载治理体验 10%，总和为 100%。综合公式为 `S = 0.15H + 0.15L + 0.20C + 0.15P + 0.10A + 0.15R + 0.10G`。结果层自身没有并列权重且不得再次参与聚合。初始研究权重只可在正式披露替代方法、全部权重值、总和、来源、适用范围与影响，并保留初始权重基线结果时由专家赋权、层次分析、德尔菲法或实证权重替换；不得静默覆盖。

## 2. 七个分析维度

### 2.1 历史文化感知

定义：公众对街区历史价值、文化底蕴、历史事件、人物故事、遗产资源、城市记忆和文化叙事的识别、理解、记忆及情感反应。

核心问题：公众是否真正看到、理解并记住历史文化资源，而不是地点客观拥有多少资源。

检索与编码内容：

- 对历史沿革、历史价值和文化底蕴的认知；
- 对历史遗址、文物建筑、传统格局等文化意义的理解；
- 对历史人物、事件、典故、地名故事和城市记忆的记忆；
- 对讲解、标识、导览、展示和文化传播效果的评价；
- 历史信息是否形成真实文化获得感；
- “资源存在但公众看不懂、找不到、记不住”之类的传播缺口。

边界：关注“知不知道、懂不懂”。资源存在、名录数量或建筑年代只能作为事实背景；没有公众感知证据时，不能直接计为正向感知。

### 2.2 在地文化特征

定义：街区文化表达与本地历史、地域文化、生活方式和社会环境之间的独特联系，以及公众对地方辨识度、文化真实性和不可替代性的感知。

核心问题：这里呈现的文化是否属于当地并具有独特性，而不是可以复制到任何地点的通用表达。

检索与编码内容：

- 本地历史文化特色和地方文化辨识度；
- 地域建筑、语言、饮食、习俗和文化符号；
- 老字号、地方传统商业和本土生活方式；
- 与其他城市商业街的差异；
- 商业同质化、全国连锁替代、过度旅游化；
- 网红化、主题化、符号化、过度包装和仿古化；
- 本地文化是否沦为商业装饰符号。

边界：关注“是不是当地自己的、有没有独特性”。文化是否仍由真实主体持续实践，归入“生活文化延续”。真实性属于不可被经济收益简单补偿的底线内容。

### 2.3 生活文化延续

定义：居民、商户、传承人等真实主体是否持续存在，以及地方生活方式、生产经营、社会交往、传统业态和社区记忆是否仍在当代发生。

核心问题：街区是否仍有人持续生活和实践，而不是只保留外观或只供短时消费。

检索与编码内容：

- 原住民和长期居民是否持续生活、正常使用街区；
- 邻里交往、社区关系和社区记忆；
- 老字号、传统店铺和传统生产经营是否延续；
- 传统市场、市井生活、日常消费和社会习惯；
- 传承主体、生产功能和传统业态的连续性；
- 居民生活空间是否被旅游和商业挤压；
- 原住民流失、传统业态退出和生活空间旅游化；
- 是否出现“只剩景观、没有生活”的文化空心化。

边界：关注“现在是否仍然有人持续生活和实践”。一般的人多、热闹、消费旺不能自动视为生活文化延续；必须识别真实主体、日常使用和持续性。

### 2.4 文化实践体验

定义：传统技艺、节庆民俗、非遗活动、文化演艺、传统仪式、文化教育、研学、市集等文化实践是否真实发生，以及公众是否实际参与并形成互动、理解和文化获得。

核心问题：文化是否真正被实践，参与者是否获得真实互动，而不只是“有没有活动”。

检索与编码内容：

- 节庆、民俗、非遗、技艺传习和传统仪式；
- 文化表演、文化市集、研学和文化教育；
- 居民、游客、青年等主体的实际参与；
- 活动常态化、持续性和文化内容真实性；
- 互动、理解和文化获得感；
- 纯表演化、舞台化、形式化和一次性展示；
- 宣传活动与真实文化实践之间的差异。

边界：关注“具体文化活动有没有真实发生、有没有参与”。日常主体连续性归入“生活文化延续”；仅有一次活动公告或数字展示不能证明活态传承。

### 2.5 场所氛围体验

定义：公众实际使用街区时，由历史环境、地方文化、社会活动、感官刺激和空间情境共同形成的整体场所感受。

核心问题：物质空间和社会活动最终形成了怎样的历史感、地方感、生活感和情绪体验。

检索与编码内容：

- 历史氛围、地方文化氛围、市井气息和烟火气；
- 视觉、声音、气味和饮食环境；
- 白天、夜间、节庆等情境中的氛围差异；
- 安静、热闹、怀旧等情绪体验；
- 历史建筑、街巷和生活活动共同形成的场所感；
- 空间条件尚存但历史氛围减弱；
- 广告、噪声、过度装修等对文化氛围的破坏。

边界：关注“人在这里总体感受到什么”。街道尺度、建筑密度、围合度等纯客观形态描述不进入本维；只有其形成明确公众感知时才纳入。

### 2.6 保护活化感知

定义：公众对历史文化资源保护、修缮、适应性利用、功能导入及传统与现代关系处理效果形成的评价。

核心问题：保护是否保住真实文化价值，同时允许街区继续使用和发展。

检索与编码内容：

- 历史建筑修缮、历史痕迹保存和“修旧如旧”感知；
- 过度翻新、仿古化和统一装修；
- 历史空间适应性再利用和老建筑继续使用；
- 新功能导入、新旧建筑和新旧业态协调；
- 商业开发对历史文化价值的影响；
- 空间保护与居民生活是否协调；
- 只有外观保护、内部功能空心化的问题。

边界：关注“保护和现代使用处理得怎么样”。游客增加、商业繁荣或店铺增多不能直接作为保护活化的正向证据；只有持续承载真实主体、文化实践和适宜功能时才具有正向意义。

### 2.7 承载治理体验

定义：公众对高强度使用产生的人流、环境、社会和空间压力，以及秩序维护、安全管理、客流组织、环境治理和利益协调效果的综合体验。

核心问题：活力是否超过空间和社区承受能力，治理是否能够有效调节压力。

检索与编码内容：

- 客流拥挤、排队、通行困难和旅游过载；
- 夜间噪声、垃圾、卫生和环境压力；
- 居民正常生活受影响、商业过载和游客居民冲突；
- 节庆或节假日高峰的承载问题；
- 客流分流、秩序管理、安全感和商贩管理；
- 环境维护、服务响应、导览和现场组织；
- 游客居民关系协调、高峰期管理和问题反馈。

边界：关注“活力压力是否可承受、治理是否有效”。站点数量、道路中心性、步行距离等纯客观交通指标不作为本维核心内容；只有客流滞留、通行冲突或居民出行受影响等公众体验才纳入。

## 3. 结果层：历史文化活态传承感知评价

该结果层是七个维度共同形成的综合判断，不是第八个并列维度。综合判断至少输出：

1. 综合分；
2. 核心优势；
3. 核心风险；
4. 底线性问题；
5. 证据充分度；
6. 评价置信度。

综合分只作为七维基础聚合的参考值。真实性损失、居民退出、文化实践消失、保护底线受损等问题具有不可简单补偿性：即使其他维度较高，也不得被平均分掩盖。结果层必须先检查底线性问题，再解释综合分，不能只凭一个分数认定活态传承良好。

## 4. 横向标签

每个独立证据单元必须有且只能有一个 `primary_dimension`，正式评分门禁、样本数、置信度和得分均只按该主维度归属。次维度和 `dimension_tags` 是横向主题标签，只用于主题覆盖、检索缺口与定性分析，不增加其他维度的正式评分证据。

主体标签固定为：本地居民、商户、游客、传承人或文化实践者、管理者、专业人士、其他公众。

时间标签固定为：当前状态、历史回忆、改造前后比较、长期变化、工作日、周末、节假日、节庆活动期间、白天、夜间。

情感标签固定为：正向、负向、中性、混合。同一文本包含不同方面时，先拆分为可独立判断的语义单元，再分别编码；每个单元使用独立 `evidence_id`、独立语义文本、唯一主维度和独立情感分值，不得给整段强行赋予单一情感，也不得让同一证据 ID 在多个维度重复计分。

## 5. 证据使用原则

- 用户评价、游记、博客、论坛、社交内容等用于形成公众感知评价。
- 政府、规划、学术、新闻和专业资料主要用于核实事实、解释背景、验证事件和补充专业判断；官方宣传不得直接充当公众正面评价。
- 严格区分“客观存在”和“被公众感知”。客观资源数量不能代替公众对文化意义或参与体验的证据。
- 严格区分“高活力”和“活态传承”。高人流、高消费和高热度不能证明真实生活、文化实践或在地文化持续。
- 没有检索到负面证据只表示当前范围内未发现充分负面证据，不能推断问题不存在。
- 每维至少保留正向与负向检索路径、主体差异和时间情境；证据不足时按维度继续深检。
- 检索有效证据、评分候选证据和实际计分证据分别统计；逐维 25/40/60 门槛与正式置信度只读取实际计分集合。

## 6. 逐维输出结构

每个维度的详细分析必须实质回答：维度定义、主要正面评价、主要负面评价、高频主题、主体差异、时间或场景差异、与客观事实的关系、主要问题、综合判断和证据充分度。报告生成结构可将主体差异、时间差异和事实关系合并在第三个三级标题下，但不得删去其中任何分析内容。

每维还必须显示：初始研究权重、提及率等级、倾向得分、转换分、检索有效证据数、主题覆盖证据数、评分候选证据数、实际计分证据数、计分正中负构成、有效计分平台、独立来源页数、来源类型数、正式评分置信度、最低置信度要求、优先置信度目标、证据状态、定向深检轮次、独立穷尽审计、中置信度终止审计及依据、编码边界和代表性来源。
