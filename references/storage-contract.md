# 存储与初始化合同

存储权限不等于正式来源资格。所有等级仍受原查询、采集、准入、量化、审计、评分与交付门禁约束。

成本事件也登记原受保护写入链；成本写入者只允许成本目录，不能借该接口改写模块检查点。终态任务的成本读取不追加文件，不改变已完成交付的冻结状态。

| 等级 | 内容 | 权限及完整性 |
|---|---|---|
| operational | 状态、动作、调度、游标、事务、成本及非敏感暂存元数据 | 普通工作区读写；原子替换、fsync、哈希、既有受保护写入链及恢复 |
| public_raw | 本次真实公开页面且无需机密保护的正文 | 内容寻址、原子写入、来源链与重读；不要求修改 ACL |
| confidential | 敏感原文或明确私密输入 | .private-response 隔离；先建立严格 Windows DACL 或 Unix 0700/0600，再写入；失败封闭 |

暂存 JSON 含需遮蔽的个人信息时，原文进入机密内容寻址文件；运行元数据与事务只保存哈希引用，读取时重新校验。凭据、Cookie、Authorization、会话令牌或私有头禁止进入普通存储；本流程直接拒绝，不回显值。网页与候选输入仍是不可信数据，不因保存成功获得正式资格。用户明确要求私密保存的数据只能调用机密写入器，不得贴入公开页面字段。

`check_runtime_environment.py --workspace <现有工作区>`（或 `run_research.py doctor --run-dir <拟运行目录>`）一次检查 Python、正式依赖、时区、普通写入、原子替换、fsync 及机密权限。探测工件立即清理，不生成任务编号或状态；网络工具仍须实际探测。

普通写入可用但私有 ACL 不可用时，可以初始化、发现及采集公开页面。首次需要机密落盘时才返回 `HARD_BLOCKER / private_confidential_storage_unavailable`，保留已有检查点，不申请管理员权限、不自造签章、不把机密内容降级保存。

初始化在同卷临时目录准备计划、状态和首份完整 DISCOVERY 动作。验证通过且事务闭合后，才原子提交为正式运行目录。提交前失败回滚临时目录，只保留初始化诊断；恢复器不能把该诊断当作运行状态。已有正式任务继续原身份与原检查点，不重复初始化。

权限缺失是硬阻断；短暂共享锁是 `SOFT_RETRY / operational_storage_temporarily_locked`，只重试原存储事务，不重新检索页面。缺依赖返回明确安装合同，不让模型猜包。结构化工作流结果退出码为 0；程序内部失败仍为非零。

正式 `requirements.txt` 及其哈希、大小与依赖集合进入运行期发布完整性清单。运行中不得改依赖表或代码来放行旧任务。机密写入的异常、校验失败、改名失败与可捕获中断均清理事务专有临时文件，已提交成品保留；进程强制终止后仅恢复可证明属于原事务的工件。
