# 查询身份、执行事实与恢复合同

在创建正式查询、写入检索执行记录、恢复旧任务或核验查询溯源前读取本文件。字段真值由 `scripts/execution_schema.py` 提供；事实重建与预算判断分别集中在 `scripts/execution_facts.py` 和 `scripts/retrieval_controls.py`。业务脚本显式传入同一任务状态派生的上下文，不自行推断日志 Schema。

## 1. 计划与执行分离

先初始化运行状态，通过正式 checkpoint 进入 `SEARCH`，再用 `build_query_plan.py --state ... --task-run-id ... --place ... --output ...` 提交计划。计划文件及绑定伴随文件必须完成事务提交；`.query-plans/registry.json` 登记内容寻址的计划、绑定快照、真实登记时间和 SHA-256。工作文件不能替代已登记快照。

同一任务内 `query_id` 唯一绑定 `plan_id`、地点规范身份、原查询、规范意图、目标维度集合、来源类型、模式、计划轮次、时间范围、语言及其他意图字段。定义或行哈希不一致会使整条重试链无效；不能选择其中一个版本继续计数。`execution_id` 标识一次实际尝试，合法重试复用查询身份，但生成新执行身份。

实际调用检索工具后，按 `assets/execution-observation-template.jsonl` 记录观察结果。占位值必须由本次真实工具结果替换；不得把计划、估计或模型生成内容写为执行结果：

字段来源、必填项和类型见同源生成的 `assets/execution-observation-schema.json`。`login_triggered`、`restriction_triggered` 在 JSON 中必须为真实布尔值，须逐项确认，不沿用模板默认值；CSV 中统一保存 `true`/`false`。`search_tool` 使用合同列出的工具类别，具体宿主工具名和调用依据写入 `notes`；不得编造工具调用。`search_id`、`state_updated_at`、`route_id`、绑定哈希与计分数量均由程序生成，观察者禁止提交。原始观察只允许 Schema 声明的身份选择器、观察字段及条件定位字段；未知、机器所有或系统所有字段即使为空、为零或恰与机器值相同也拒绝。实际起止、检索时间、工具、状态、动作和计数缺失时，在写入前拒绝。

查询文本、目标维度、缺口、来源类别、模式、目标置信度和轮次前置信度由提交器从已经验证的计划继承。观察输入不得携带同名校验副本，只允许使用计划身份选择器。深检计划必须绑定实际机器维度审计及执行历史的不可变字节快照；轮次前置信度从快照中的目标维度状态确定性派生，多维不同状态使用按名称排序的 JSON 对象，不能填“待定”或猜测。快照同时绑定任务、维度、轮次、目标置信度、审计和历史哈希、审计事务及计划生成时间；后续覆盖工作文件不改变已归档身份。基础轮不要求非空缺口。

```text
python scripts/execution_facts.py --state "运行状态.json" --writer-ledger "protected_artifact_write_ledger.jsonl" --observations "staging/执行观察.jsonl" --output "检索日志.csv"
```

观察输入必须提供合法 `plan_id`、`query_id`、唯一 `execution_id`、实际起止时间、检索工具、状态、实际返回/打开/相关/重复数量和访问限制。状态与动作的唯一矩阵位于 `scripts/execution_semantics.py`；动作只描述路线，不直接授权评分、终止或交付。计数为非负整数；不能用布尔值、负数或小数代替。首次执行 `retry_number=0` 且重试信息为空。重试理由和间隔策略从 `retrieval_controls.py` 的受控枚举读取，必须引用首试 `original_execution_id`，编号连续且未超过固定上限；前一次必须是无访问限制的瞬时失败或部分结果，且其 `error_type` 与本次 `retry_reason` 一致。完成、无结果终止、永久错误、登录墙或正式阻断不能伪装成可重试状态。

| 状态 | 实际尝试及资源 | 新独立意图有效覆盖 | 可有来源 | 允许下一动作 |
| --- | --- | --- | --- | --- |
| completed | 计入 | 计入 | 按真实页面数量 | continue / exhausted / not_applicable / target_met |
| partial | 计入 | 计入 | 仅实际已取得部分 | continue / retry / exhausted |
| blocked | 计入 | 计入 | 仅受阻前已取得部分 | continue / exhausted / not_applicable |
| no_results | 计入 | 计入 | 不允许 | continue / exhausted / not_applicable / target_met |
| failed | 计入 | 不计入 | 不允许 | continue / retry / exhausted / not_applicable |

表中覆盖仍须通过查询身份、首试去重、目标维度和全部其他规则；重试不额外贡献普通轮八条或增强轮十条覆盖。失败首试仍消耗独立意图预算，不能以失败不计覆盖为由无限重试。所有来源还须通过原有采集、准入和正式评分资格，不因状态允许产出而自动计分。

`target_met` 必须引用同任务已经正式写入且达成全部目标的机器审计：填写 `target_audit_file`、`target_audit_sha256`、`target_audit_state_file`、`target_audit_writer_ledger`，路径均相对运行根目录。程序重验哈希、允许的审计写入者、任务身份、总体和逐维目标。尚无该依据时使用真实的继续动作，等待正式审计决定终态；不得补写审计或把该字段当作目标达成证明。任何非法执行仍是硬错误，不受该动作覆盖。

脚本从登记计划恢复查询定义，生成单调 `event_sequence`、行绑定与执行绑定哈希；`event_sequence` 仅为接收序号，不是逻辑事件顺序。观察记录不得重定义查询。新增/累计正式计分数初始化为零，随后仅由 `refresh_search_log.py` 从正式证据刷新，不接受观察者填入任何派生计数字段。相同观察再次提交时保留已受保护刷新后的计数，不以原始零值覆盖。计划占位或未执行记录不计入任何执行量；缺凭据、身份冲突或时间异常是明确错误，不能当作不存在后继续交付。

## 2. 时间、来源与确定性

`started_at`、`finished_at`、`state_updated_at` 和来源 `retrieved_at` 使用带时区 ISO 8601，统一转换为 UTC 比较。已执行记录不得使用未来时间；完成不得早于启动；重试启动不得早于前次完成，重试事件不得早于前次路线事件；后续轮次不得早于前序轮次完成。进入下一轮还必须通过状态机和正式审计准入。路线事件时间不得早于所引用执行。逻辑排序按真实事件时间、任务和查询身份、重试编号及起止时间重建，最后才用执行身份消除平局。独立事件迟到不构成时间冲突；不得改动真实时间或执行身份。缺首试的重试返回 `orphan_retry`，保留原始观察，首试登记后可原样重新提交；缺号、重号、错误引用及真实因果冲突均拒绝。CSV 物理位置和接收序号均不能决定路线终态或计分归属。

采集记录从实际执行复制 `execution_facts.SOURCE_BINDING_FIELDS` 定义的全部机器字段，包括执行/查询/计划身份、缺口、轮次前置信度、审计快照与计划绑定哈希；同时保留同一 `task_run_id`、`query_id` 和真实 `query_text`。证据通过唯一来源身份继承这条绑定。来源采集时间必须位于对应执行窗口内。页面读取属于该次执行的一部分；若读取尚未结束，不得先写虚假的完成时间。

所有执行、检索、采集时间由 `temporal_fields.timestamp()` 严格解析带秒和显式时区的完整 ISO 文本；拒绝无时区、非法日期、前后垃圾字符、非法偏移及时间倒序。发布日期由 `publication()` 接受真实日历上的年、年月或年月日，保留原精度；未知时为空，不能补造年月日。非法发布日期是硬错误，不贡献年份覆盖。域名采用 `source_identity.trusted_domain()` 从 HTTP(S) URL 派生完整主机名，规范大小写、尾点和国际化域名；不改为可注册主域层级。正式来源的 `url` 为受保护采集 URL，不能用未验证的跳转声明替换。显示 `domain` 与实际主机名不一致时拒绝，不贡献来源多样性或穷尽依据。

`source_id → execution_id → query_id → plan_id` 必须完整可复算，证据再经 `source_id` 回溯。页面去重不删除合法发现关系：不同查询再次发现同页时追加采集/来源关系并保留各自执行绑定，页面实体统计仍只计一页。不得覆盖首次发现记录或将所有增益归给共享查询的第一行、最后一行。查询、来源和证据集合的机器摘要采用稳定集合排序；原始文件哈希仍按实际字节校验，物理重排不会改变研究结论，但不得绕过受保护写入登记。

`query_ids` 仅列真实查询身份；`execution_ids` 仅列执行身份；`independent_intent_ids` 为规范意图身份。三者稳定排序且互不替代。

查询有效事实摘要排除接收序号，因此同一组真实事件按不同到达顺序或批次提交所得事实、审计和统计一致；原始字节、写入登记及事务哈希仍验证接收记录本身，不能用逻辑摘要代替原始完整性检查。

页面计数是该次真实打开情况，来源台账是保留的发现关系：按规范 URL 去重后的来源页数不得超过 `opened_pages`，相关来源页数不得超过 `relevant_pages`；重复页和相关页均不得超过打开页数。无结果的返回、打开、相关、重复数全部为零；失败不得有已打开页面或来源，已取得部分结果应如实标为部分完成。搜索卡片不是已打开页面，沿真实公开链接继续读取时允许打开数超过返回卡片数，不凭空增加相反限制。违反组合规则的来源与证据全部排除并重新计算页面、实际计分证据和维度置信度，同时保留硬错误，不能先计数后只警告。

## 3. 两类预算

独立意图预算只由合法首试中此前未出现的新规范意图消耗。实际尝试预算由首试及合法重试共同消耗；重试另计重试额度。跨查询编号或跨轮次重复意图也不得增加独立覆盖。规划器扣减独立意图已用数，不能用包含重试的 `deep_executed_query_count` 或 `deep_queries_by_dimension` 扣减独立额度。

具体边界只读 `assets/retrieval-control.json`，规划可行性由 `planning_budget_account()` 和 `deep_search_budget_feasibility()` 共用。机器结果分列额度、已用、剩余、后续必需意图、后续必需尝试、`planning_feasible` 和稳定错误代码。额度不足、实际资源不足和重试超限分别报错。预算到达不等于维度穷尽，也不授权评分或受限交付。

## 4. 显式上下文与旧任务迁移

任务初始化保存实际状态身份快照；`context_from_state()` 从该快照、当前查询登记及迁移清单派生 Schema 名称、修订、兼容依据、任务编号、创建时间、截止点、状态哈希、迁移状态和严格要求。所有消费者复验完整上下文，缺失时失败，不默认选择新旧规则。运行位置只作为显式运行期属性，不写入公共哈希；目录移动后用当前状态路径重新绑定，不能继续引用旧目录。

历史兼容仅适用于固定截止点之前创建、状态修订合法且真实旧状态没有新声明的任务。必须有可验证的已提交计划以及真实起止时间；不能根据一条记录自称旧格式、只给日期或临时补造计划授予兼容资格。允许显式运行：

```text
python scripts/execution_facts.py --state "运行状态.json" --migrate-legacy "原始历史执行.json"
```

迁移接受 CSV 或 JSON 数组，保存原始字节与 SHA-256，建立原记录到严格事实记录的映射，不覆盖原文件。缺计划、时间、身份或存在冲突时返回兼容错误，不能静默忽略。仅与归档原始记录哈希完全一致的旧记录获得迁移；后续新执行仍必须满足严格合同。迁移完成后各入口重新从同一状态加载上下文，不能沿用迁移前的旧上下文。

## 5. 幂等与故障恢复

### 受审计执行更正

不得直接修改原始日志。仅在 `SEARCH` 阶段，通过同一受保护入口提交追加事件：

```text
python scripts/execution_facts.py --state "运行状态.json" --writer-ledger "protected_artifact_write_ledger.jsonl" --amendments "staging/执行更正.jsonl" --output "检索日志.csv"
```

每条请求必需 `event_id`、`event_type`、`target_execution_id`、带时区 `event_time`、`reason`、当前有效记录的 `old_record_sha256`；不是首个事件时还需 `previous_effective_event_id`。记录摘要由 `execution_amendments.record_hash()` 计算，排除可刷新计分数；不能手填摘要。

以上请求字段均为字符串，不接受未声明字段、容器替代文本或未来事件时间；事件时间不得早于执行完成或该记录的前一有效事件。新计划还会复核当前更正事件摘要和有效执行集合，不能仅凭未改变的原始 CSV 复用旧审计。

- `correction` / `supersede`：从原记录和已登记计划确定性恢复缺失机器字段及绑定。替代形成新的有效事件身份，不生成第二次工具调用，也不修改实际 `execution_id`。无独立可信观测可还原的工具、时间或计数缺失，必须拒绝；本入口不接受自由 `updates` 或 `replacement`，应废止并真实重检。
- `retract`：保留原记录，终止该记录正式来源与证据资格，重新量化和刷新计分数后重新审计。已经发生的真实调用仍消耗资源和独立意图预算，但不贡献完成覆盖；不能利用废止重置预算。
- `correction_rejected`：自动保存不合法尝试及拒绝原因，不修改有效事实。相同事件请求重放幂等，不同内容复用事件编号、分叉、循环或废止后重开均拒绝。

原记录、事件、理由、前后摘要和事件链保存在 `.execution-events/` 的受保护、不可变归档；工作索引按事务原子更新。事实层、刷新器和审计读取同一有效视图；原始台账不覆盖。更正清单哈希属于执行上下文，任何变化都会使旧上下文和审计失效。事务准备、替换或登记后中断时原样重新调用恢复，不手工修复文件。最终验收会重新验证这一来源链。

执行日志与受保护写入登记使用跨进程锁和可恢复预写事务。事务绑定固定任务身份、实际引用的计划快照与绑定快照哈希、对应登记条目哈希、查询行及执行身份、相对路径、旧/新输出哈希、旧输出长度与安全前缀、写入台账已确认前缀及完整待写内容；不把整个可变查询登记表哈希当作旧事务的永久身份。待恢复时不允许新建计划，恢复完成后新增无关合法计划不影响历史重放，但已引用依赖、原有前缀或任务身份改变仍失败封闭。恢复时重新验证当前登记及全部引用依赖，再完成日志和登记；两者都完成后才返回成功。同一观察重复提交不新增记录；不同事实报身份冲突。已提交事务保存在 `.execution-transactions/`，受保护写入登记引用该不可变事务文件；不得修改状态、补写台账或忽略错误来恢复。

## 6. 统一边界门禁

字段所有权在提交、迁移、事实重建、核心审计及最终验收重复校验。条件定位字段 `target_audit_file`、`target_audit_sha256`、`target_audit_state_file`、`target_audit_writer_ledger` 只允许引用已有受保护机器审计；`target_met` 时缺一即拒绝，其他动作必须缺省或为空。观察者不能生成审计内容；程序重新验证同任务状态、允许写入者、哈希和正式目标。

路线身份使用 `execution_semantics.route_id()` 从登记计划的任务、对象身份、检索入口、规范意图、来源目标、维度、模式、时间、极性、主体、平台和访问条件派生。相同工具不表示同一路线；更换工具不人为增加路线。入口下实质不同的目标或意图分开，同一定义跨轮复用身份。状态按受验证事件因果顺序取最新；较早阻断不能覆盖后来继续，尚有活跃路线时不能宣布全维路线耗尽。

时间偏移最多 ±14:00。执行不得早于任务创建、最近进入 SEARCH、计划生成、计划登记及本轮审计准入；这些边界取自受保护状态和计划快照，不取观察者输入。`state_updated_at` 由提交器使用受验证完成时间，合法更正另由受保护事件链排序。最终完成不能早于上游事件。发布日期不能晚于实际采集日、检索日、受保护研究截止日及当前日期的最早边界；部分日期按已知精度判定，不补造日月。未来活动预告只作事件信息，不作发布日期或年份覆盖。

公开网络来源统一通过 `input_safety.py`、`public_network.py` 与 `host_receipts.py`。普通路径保存 `tool-page-observation-1`，由真实页面工具结果及其引用、请求/最终 URL、标题、访问时间、任务/计划/执行/采集身份和原始结果哈希构成，不要求 DNS 或连接 IP。可选签章路径继续使用 `public-network-observation-1` 逐跳核验真实公开连接。两类均拒绝本机、私网、链路本地、非法主机、凭据与身份冲突，不能把自由文本自洽等同于实际读取。完整字段见 `host-page-receipts.md`。

采集器保存工具读取记录或可选签章、原始结果及规范观察哈希、真实 `final_url`、固定映射及正文处理规则哈希，并沿准入、来源和证据传导。最终审计离线复验当前任务工具引用、原始结果、正文提取/脱敏和定位；签章路径额外验签，不重新查询 DNS 覆盖旧事实。无本次实际联网依据的自报内容不得正式计数、评分或支撑穷尽。哈希只证明内容完整性，普通工具溯源不宣称密码学不可伪造。

正式页面哈希、`domain`、`content_domain`、平台身份均使用经来源溯源验证的 `source_identity_url`（规范化最终 URL）；`url/request_url/discovery_url` 与 `discovery_domain` 保留发现路径，不额外增加内容域名。旧身份哈希必须经显式重新采集或迁移复验，不能把两种哈希静默同时放行。

平台唯一由验证过的 URL、最终跳转和固定映射派生。来源或证据的平台显示值、缓存与机器身份冲突时拒绝，未知公共主机保持独立，不能自由命名制造平台多样性。非法来源身份、来源时间、平台或执行绑定使相应来源及证据排除，并保留硬错误，不能增加页面、平台、域名、维度或穷尽依据。

执行观察与执行更正共用运行级协调锁，再按固定顺序取得局部锁。存在任一未完成执行/更正事务时，状态、计划及其他正式写入入口先拒绝；新执行/更正入口先恢复原事务，再提交本次请求。可显式运行：

```text
python scripts/execution_facts.py --state "运行状态.json" --writer-ledger "protected_artifact_write_ledger.jsonl" --recover-transactions
```

恢复只重放原事务，不能补写未知内容。无法排序的多个待恢复事务、路径逃逸、引用变化或损坏前缀均失败封闭并保留事务。重复恢复不增加记录，重复观察不重置已刷新计分数。恢复完成后才可创建新计划或继续正式写入。
